# Interview Agent — 项目交接 HANDOFF

> 交接快照。长期规则见 `CLAUDE.md`，本文件只描述当前进度、注意事项和下一步。

## 1. 项目目标

基于自研轻量决策图编排框架的智能面试评估系统。面向 Go 后端岗位，核心能力：

- 自适应选题：`pick_next` 结合 `GapStrategy` / `SkillCoverage`
- 动态追问：`critic` 判信号后进入 `probe_ask` / `probe_eval` 循环
- Critic-Refine：对初评结果做二次反思和修正
- WorkingMemory：跨轮维护已确认技能、薄弱技能、覆盖度和预算
- Reflection：每轮结算后决定继续、补漏或结束
- Report：本地聚合生成结构化复盘报告
- Mock / Real 双模式：LLM 与 Embedder 都可切换

- SSE 流式接口：`GET /api/interview/stream?session_id=...`，先发 snapshot，再转发 session / graph 事件。
- SSE 支持 `Last-Event-ID` / `last_event_id`，内存事件总线会回放该 ID 之后的历史事件，便于断线重连；普通新连接只发 snapshot 后等待新事件。
- SSE 会定期发送 `: ping` heartbeat，降低空闲连接被代理断开的概率。
- 内存事件总线会先回放历史再注册 live subscriber，避免重连时 live 事件插到 replay 前面；事件里的 question/report 会复制快照，避免历史事件被后续 session 变更污染。
- `InterviewEventHub` 已有 `Close()` 生命周期接口；server cleanup 会关闭 hub，SSE 会在事件通道关闭时退出。
- 修复了 `MemoryInterviewEventHub.Publish` 与 `Close` 并发时可能向已关闭 subscriber channel 发送的问题；现在发送在 hub 锁内完成，`Close` 不会交叉关通道。
- 当前 Windows 环境运行 `go test ./internal/httpapi -race -count=1` 会以 `0xc0000139` 崩在运行时层，非测试断言失败；普通 `go test ./... -count=1` 已通过。
- Redis Streams 事件总线已有最小实现：设置 `INTERVIEW_REDIS_URL=redis://localhost:6379/0` 或 `rediss://...` 后，`cmd/server` 会在 `buildInterviewEventHub` 中选择 `RedisInterviewEventHub`；未设置时仍使用内存 hub。
- Redis hub 使用标准库 RESP 实现，没有引入新的 go.mod 依赖；当前测试覆盖 URL 解析、RESP 编码/解析和 stream event 解码。

## 5. 如何启动项目

Mock 模式基础服务：

```bash
make run
curl http://localhost:8080/healthz
curl http://localhost:8080/readyz
curl http://localhost:8080/api/ping
```

数据库路径：

```bash
make docker-up
export INTERVIEW_POSTGRES_DSN="postgres://interview:interview@localhost:5432/interview?sslmode=disable"
make migrate-up
go run ./cmd/reindex -seed seeds/question_bank.json -mode mock
make run
```

Real 模式需要：

```bash
export INTERVIEW_LLM_API_KEY=sk-xxx
export INTERVIEW_EMBEDDING_API_KEY=sk-xxx
```

不要把 key 写进 YAML。

## 9. 隐藏假设 / 临时方案

- `Score = -1` 表示评估失败，和 `Score = 0` 严格区分。
- probe loop 通过 `probe_eval` 改写 `CriticResult.HasProbeSignal` 实现。
- reflect 复用 `pick_next` 造环，补漏 topic 存在 `WorkingMemory.ReflectTopic`，由 `pick_next` 消费并清空；兼容消费旧 `Notes["reflect_topic"]`。
- `AvgScore` 用增量公式，计数存在 `WorkingMemory.ScoredRounds`；降级轮次存在 `WorkingMemory.DegradedRounds`。
- `SkillCategory` 优先于 `Tags` 做覆盖度聚合。
- `fallbackRetriever` 只用于未配置 PG DSN 时触发 RAG fallback，不是长期检索实现。
