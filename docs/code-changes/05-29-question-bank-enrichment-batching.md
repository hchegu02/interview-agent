# 05-29 Question Bank Enrichment Batching

## 背景

本地题库导入的 LLM 元数据补全不能把所有缺字段题目一次性塞进一个 prompt。大文件会触发上下文过长，且 LLM 少返回题目时不能静默降级。

## 变更

- 本地题库 LLM 补全改为固定批量处理。
- 每个批次要求 LLM 为输入中的每道题返回一项。
- 补全结果按 `id` 匹配，必要时按原始 `content` 精确匹配。
- 如果 LLM 漏题，导入任务失败，不再静默暂存未补全题。

## 验证

- 新增测试覆盖批量调用次数。
- 新增测试覆盖 LLM 漏返回题目时导入失败。
