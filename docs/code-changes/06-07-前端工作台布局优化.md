# 06-07 前端工作台布局优化

## 1. 变更概述

本次变更优化候选人工作台的信息层级和布局：

- 将面试模式选择从全局侧栏移到 JD 准备流程中。
- 将面试页和报告页的 Agent 状态、SSE 事件、RAG 检索链路归入“辅助诊断”区域。
- 调整报告页顺序，让总分、总结、训练计划、逐题证据先于后端诊断信息。
- 补充窄屏布局规则，减少侧栏和底部回答框对主任务区域的挤占。

变更不修改后端 API、Session JSON 字段、SSE 契约、RAG、评分或 Agent Graph 决策。

## 2. 变更文件

- `web/src/main.tsx`
  - 移除侧栏里的模拟/考试全局切换。
  - 为工作区切换按钮增加折叠态短标签。
  - 向 `JDPage` 传入 `setMode`。
- `web/src/candidatePages.tsx`
  - `JDPage` 增加 `setMode` prop 和页面内面试模式控制。
  - `InterviewPage` 将 practice 诊断信息包入 `AuxiliarySection`。
  - `ReportPage` 调整模块顺序，并将 WorkingMemory / RetrievalTrace 包入 `AuxiliarySection`。
  - 新增本地辅助组件 `AuxiliarySection`。
- `web/src/styles.css`
  - 增加 JD 模式面板、辅助诊断区、报告辅助区样式。
  - 调整折叠侧栏工作区切换样式。
  - 调整窄屏侧栏、主内容、回答 dock 和 conversation 底部留白。
- `web/src/candidatePages.test.tsx`
  - 增加布局顺序和辅助诊断分组测试。
  - 更新 `JDPage` 测试调用以传入 `setMode`。
- `internal/httpapi/web/dist/*`
  - `npm run build` 生成新的 Vite 静态产物 hash 文件。

## 3. 函数级说明

### `App` (`web/src/main.tsx`)

- 位置：应用入口组件。
- 作用变化：
  - 侧栏仅保留工作区切换，不再承载模拟/考试模式切换。
  - 工作区切换按钮增加 `data-short`，供折叠侧栏显示短标签。
  - 渲染 `JDPage` 时传入 `setMode`。
- 输入：无外部输入变化，仍使用组件内部状态。
- 输出：React 页面结构。
- 副作用：不新增副作用；现有导航、Session 拉取、SSE 订阅流程不变。
- 错误处理：无变化。

### `JDPage` (`web/src/candidatePages.tsx`)

- 位置：JD 分析页面组件。
- 作用变化：
  - 新增必填 prop `setMode: (mode: Mode) => void`。
  - 在“准备检查”控制面板内新增“面试模式”选择，提供“模拟”和“考试”两个按钮。
  - practice 模式仍显示题库范围；exam 模式仍隐藏题库范围。
- 输入：
  - 新增 `setMode`。
  - 既有 `draft`、`mode`、`busy`、`updateDraft`、`analyze`、`startInterview` 不变。
- 输出：React 页面结构。
- 副作用：点击模式按钮调用上层 `setMode`，只改变前端本地面试模式状态。
- 错误处理：无变化。

### `InterviewPage` (`web/src/candidatePages.tsx`)

- 位置：面试页组件。
- 作用变化：
  - practice 模式下，`AgentStatePanel` 和 `EventTimeline` 归入 `AuxiliarySection title="辅助诊断"`。
  - 当前题、历史轮次、pending answer、busy 状态和回答输入仍在主流程。
  - exam 模式仍不展示内部诊断。
- 输入：无 prop 变化。
- 输出：React 页面结构。
- 副作用：无变化；提交回答仍通过 `submitAnswer`。
- 错误处理：无变化。

### `ReportPage` (`web/src/candidatePages.tsx`)

- 位置：报告页组件。
- 作用变化：
  - 模块顺序调整为：总分和技能拆解、报告总结、训练计划、逐题评分、回答诊断、JD/简历分析、辅助诊断。
  - practice 模式下，`AgentStatePanel` 和 `RetrievalTracePanel` 归入 `AuxiliarySection title="辅助诊断"`。
  - exam 模式仍隐藏内部诊断。
- 输入：无 prop 变化。
- 输出：React 页面结构。
- 副作用：`startDrill` 和 `jumpQuestion` 调用链不变。
- 错误处理：无变化。

### `AuxiliarySection` (`web/src/candidatePages.tsx`)

- 位置：`candidatePages.tsx` 本地辅助组件。
- 作用：用原生 `details open` 包装辅助诊断内容，提供统一标题和内容容器。
- 输入：
  - `title: string`
  - `children: React.ReactNode`
- 输出：包含 `section.auxiliary-section`、`summary` 和 `.auxiliary-content` 的 React 结构。
- 副作用：无。
- 错误处理：无。

### 测试辅助函数 (`web/src/candidatePages.test.tsx`)

- `markerIndex(html, marker)`：
  - 先断言 marker 存在，再返回其位置。
  - 用于避免 `indexOf` 返回 `-1` 时顺序断言误通过。
- `sliceFrom(html, marker)`：
  - 从已验证存在的 marker 位置截取 HTML 片段。
  - 用于断言辅助诊断区域之后包含指定内容。

## 4. 调用链

### JD 模式选择

```text
用户打开 JD 页面
  -> App 根据 route 渲染 JDPage
  -> App 传入 mode 和 setMode
  -> JDPage 渲染“面试模式”按钮
  -> 用户点击“模拟”或“考试”
  -> JDPage 调用 setMode
  -> App 更新 mode
  -> startInterview 使用当前 mode 组装请求
```

### 面试辅助诊断

```text
用户进入面试页
  -> App 渲染 InterviewPage
  -> InterviewPage 渲染当前题、历史轮次、回答输入
  -> 如果 session.mode === "practice"
     -> AuxiliarySection("辅助诊断")
     -> AgentStatePanel(session.working_memory)
     -> EventTimeline(events)
  -> 如果 session.mode === "exam"
     -> 不渲染内部诊断
```

### 报告辅助诊断

```text
用户进入报告页
  -> App 渲染 ReportPage
  -> ReportPage 渲染 report-hero、report-summary、DrillPlanPanel、ReportRoundReviews
  -> 如果 session.mode === "practice"
     -> AuxiliarySection("辅助诊断")
     -> AgentStatePanel(session.working_memory)
     -> RetrievalTracePanel(session.retrieval_trace)
  -> 如果 session.mode === "exam"
     -> 不渲染内部诊断
```

## 5. 数据流

- Draft 数据仍来自浏览器本地草稿。
- `mode` 仍由 `App` 维护，只是选择入口从侧栏迁移到 JD 页。
- `startInterview` 请求仍使用当前 `mode`，practice 模式仍会传 `question_bank_filter`，exam 模式仍不传。
- `Session` 仍是面试页和报告页的权威数据源。
- SSE `events` 仍只作为面试页辅助诊断展示，不参与状态决策。
- `retrieval_trace` 仍只在 practice 报告页展示，不参与前端排序或 rerank。

## 8. 风险

- 视觉效果仍需浏览器实际检查，尤其是折叠侧栏和移动端 answer dock。
- `details open` 当前默认展开，降低了主流程干扰但不是完全折叠；如果后续要默认折叠，需要重新评估可发现性。
- `internal/httpapi/web/dist` 与主工作区已有 dist 改动是不同工作区状态，合并前需要单独处理冲突和 hash 文件。
- `JDPage` 新增必填 `setMode` prop，仓库内当前调用已更新；外部若直接复用该组件，需要同步传入。
