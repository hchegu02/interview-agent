# 📚 面试讲解材料总索引

> 本目录是你**面试讲解项目的完整素材库**。从简历描述到 8 大亮点深度剖析、30 道 QA、Mermaid 架构图，所有材料都为面试设计。

## 🎯 怎么用这份材料（按面试阶段）

### 📅 投简历前（修简历用）

→ **`00-简历项目描述.md`**（1 句话 / 3 句话 / 10 句话 / STAR 4 维度）

- 简历项目栏抄一句话版本
- 自我介绍口播抄 3 句话版本
- 项目深聊用 10 句话 + STAR 框架

### 📅 笔试 / HR 面（5-10 分钟）

→ 重点过 **`01-项目背景与目标.md`** + **`02-系统架构总览.md`**

- 业务动机 + 技术挑战 + 北极星指标
- 三层架构图能在 1 分钟内画出来

### 📅 项目深度面（30-60 分钟，金山云风格）

→ 8 大亮点 + `99-面试QA清单.md` 配合使用

**面试前 1 周**：通读全部 8 个亮点文档，**关键代码自己再过一遍**
**面试前 1 天**：背 30 道 QA 答案，**特别是"为什么"类问题**
**面试当天**：开场 2 分钟讲 `01-项目背景` + `02-架构总览`，深聊环节按面试官关注点切到对应亮点文档

### 📅 技术总监 / VP 面（架构判断 + 取舍能力）

→ 重点准备每个亮点的"**为什么不选 X**"和"**和 Y 的对比**"部分

- 选型对比表（背熟）
- "可能的追问"段落（特别是"如果规模上 100 倍怎么办"类）

## 🎙️ 临场技巧

### 主动展示（Show, don't tell）

- 投影时**直接打开代码**：`internal/graph/graph.go` line 268-294（frontier 算法）
- 跑一次 `make demo-mock` 给面试官看 `run.json`
- 画架构图时**用纸笔实时画**，不要照念 PPT

### 引导面试节奏

- 主动提"**这里有个我想讲的取舍**"，把面试官引到自己准备充分的部分
- 主动提"**你想从哪个亮点开始？**"，让面试官选
- 主动提"**这部分还有个 TODO**"，体现自知 + 后续规划

### 遇到不会的问题

- "**这个我没系统想过，但我的第一反应是 A，因为 B；可能的坑是 C**"
- 千万别硬撑，**坦诚 + 现场推理** 比假装懂更打动面试官

### 表达"取舍意识"

每讲一个技术决策都补一句：
- "如果规模变 100 倍，我会切到 X，但当前 SLA 不需要"
- "这里有个简化，生产可以加 Y，但 ROI 不划算"
- "选这个的代价是 Z，但我用 W 弥补了"

> **面试官最看重的不是你做了什么，是你为什么做这个不做那个**。
